# Forest Navigator: user guide

This guide explains how to set up the survey folder and use the layers.
It was written from the app's screen labels and messages. Check it on your phone and
tell us what differs.

## 1. Install the app
Install the APK for your Android version (see the Releases page). Allow "Install unknown apps"
for the app you open the APK with.

## 2. Choose the survey folder
1. Open **Settings** and choose the folder that holds the survey layers.
2. When the folder is set, the app confirms **Folder set**.
3. If you see "That folder could not be opened" or "Android would not let the app read that folder",
   move the folder onto the phone's internal storage and pick it again. Folders on an SD card or
   in another app's storage are often refused.
4. The layers and the `project.json` file (layer list and map settings) should sit in that folder.

## 3. Map and layers
- **Start_MAP** opens the map. **Close_MAP** closes it.
- **Layer settings** lets you turn layers on or off and change their style.
- **Verify layers** checks the layers in the folder before you go into the field.
- **Start Editing** opens the layer you want to edit.
- **Start track** records a track while you walk. The track is saved to its own layer.

## 4. Before going into the field
1. Run **Verify layers** and fix anything it reports.
2. Start the map once with the phone's GPS on, so the position is known.
3. Stop recording or editing before changing the folder. The app asks you to stop first.
